# St. Moritz / Aspen / Niseko — Photography QA

The importer intentionally creates **unapproved real-media candidates**, not commercial publication rights, true hotel match certification or a live destination route.

- 12 distinct photographs per destination: exact official property pages, three photos for each of four independently verified hotels.
- 9 independently named destination scenes per destination: Commons file titles, license metadata, original file source retained.
- All downloaded items are WebP with a SHA-256. Hotel identity, accurate scene geolocation and the full licence are **not proven** by a successful HTTP download.
- If a hotel site is blocked or 403: record missing and move to manual source review. Do not substitute a different hotel or invent a generic property.
- Inspect each WebP visually; reconcile any image mistaken for a different hotel, restaurant, spa, area or season. Compare Commons attribution and any ShareAlike obligations.
- After authentic visual QA, create richer metadata with factual FR/EN captions, confirm image rights, and register the guide + FAQ + photo manifests through existing featured city components.
- **No Preview Vercel** until ten destinations pass QA. No Wink bookability or live prices may be claimed.
