- **Villa Miraé** — Garoupe · ancienne Impérial Garoupe. Source officielle : https://www.villamirae-capantibes.com/

Cap d’Antibes Beach Hotel est le cinq étoiles de 35 clés près de Port Gallice et Port du Crouton. Eden-Roc est saisonnier.
