# Travel localization release

All 88 manually rewritten Russian and Arabic destination guides are in the explicit release inventory, alongside the existing FR/EN guides. Both destination and hotel-selection routes in four languages share one indexation gate. CI checks 704 guide routes, canonical URLs, reciprocal hreflang, sitemap membership, localized metadata and 352 RU/AR server-rendered views. No technical, duplicate, unimplemented or unsupported-locale route is added to the release. Existing photography eligibility and booking mappings are not modified. Browser visual review and search engine indexing are separate checks, not guaranteed by server rendering.
