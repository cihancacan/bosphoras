# Pamalican Island / Amanpulo — official source research, 27 Oct 2026

Amanpulo is a single Aman resort, not four hotels. Four curated official categories: Beach Pool Casita, Treetop Pool Casita, Grand Beach Pool Casita, and Four-Bedroom Villas (east Lagoon / west Palawan). Never attribute pool facilities to non-Pool casitas or advertise a generic villa photograph as the exact booked four-bedroom villa.
